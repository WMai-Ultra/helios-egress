# 凭据管理与脱敏规范

本仓库为**对外发布副本**。所有敏感信息以占位符形式呈现，部署时由本地配置注入。

---

## 1. 敏感信息分类

| 类别 | 示例形态 | 处置方式 |
| --- | --- | --- |
| 云端凭据 | 访问令牌、账号标识、命名空间标识 | 占位符 `${CF_API_TOKEN}` / `${CF_ACCOUNT_ID}` / `${CF_KV_NAMESPACE_ID}` |
| 运行时口令 | 监控台口令、同步密钥 | 占位符 `${ADMIN_PASSWORD}` / `${SYNC_SECRET}` |
| 传输凭据 | 传输层 UUID | 占位符 `${VLESS_UUID}` |
| 主机标识 | 边缘主机名、隧道主机名、隧道标识前缀 | 占位符 `${WORKER_HOST}` / `${TUNNEL_HOST}` / `${TUNNEL_ID_PREFIX}` |
| 网络地址 | 中继节点地址、接入点地址 | 占位符 `${NODE_nn_IP}` / `${CF_ANCHOR_n}` |
| 订阅用户标识 | 订阅令牌、用户名 | 占位符 `${USER_TOKEN_n}` / 匿名编号 |
| 设备标识 | 设备型号、序列号、无线网络名 | 占位符 `${DEVICE_MODEL}` / `${PHONE_SERIAL}` / `${WIFI_SSID}` |
| 地理与运营商 | 城市名、运营商名、接入点代码 | 中性代号（`R1`…`R6`） |

---

## 2. 导出流程

对外发布副本由专用导出管线生成，不允许手工复制粘贴：

```
源码 ──① 精确替换（占位符化）──▶
     ──② 标识类信息匿名化 ──────▶
     ──③ 术语规范化 ───────────▶
     ──④ 凭据复扫（必须 0 命中）─▶ 发布副本
```

| 步骤 | 作用 |
| --- | --- |
| ① 精确替换 | 按"原文 → 占位符"逐条替换，命中数为 0 视为异常并中断（防止漏改） |
| ② 匿名化 | 用户标识、地理信息、运营商、设备信息统一替换为中性表述 |
| ③ 术语规范化 | 口语化措辞替换为工程规范用语 |
| ④ 复扫 | 全量扫描真实值，**出现任意一处即视为失败** |

---

## 3. 提交前检查清单

| 检查项 | 判定 |
| --- | --- |
| 真实凭据残留 | 0 处 |
| 真实域名残留 | 0 处 |
| 真实网络地址残留 | 0 处 |
| 真实用户标识残留 | 0 处 |
| 设备与地理标识残留 | 0 处 |
| 脚本语法检查 | 通过 |

上述检查由自动化脚本执行，人工只需确认脚本退出码为成功。

---

## 4. 运行环境要求

| 项 | 要求 |
| --- | --- |
| 令牌最小权限 | 部署令牌仅授予边缘脚本与键值存储所需权限 |
| 口令复杂度 | 监控台口令与同步密钥不得使用默认值，部署前校验 |
| 配置不进版本库 | `.env` 与节点侧真实配置一律列入忽略清单 |
| 备份含密 | 备份文件包含占位符化后的内容；真实配置备份仅保存在本地受控目录 |

---

## 5. 事件处置

若凭据疑似泄露：

1. 立即轮换对应凭据（传输凭据、口令、隧道标识）；
2. 重新生成订阅配置并通知授权订阅用户更新；
3. 复核导出管线，确认泄露路径已被封堵；
4. 在变更记录中登记事件与处置结果（不记录真实值）。
