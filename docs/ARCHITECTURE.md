# 系统架构

本文描述平台的分层结构、数据流向、关键时序与主要设计约束。

---

## 1. 分层模型

| 层 | 组成 | 主要职责 |
|---|---|---|
| 接入层 | 任播边缘（Worker） | 就近接入、TLS 终止、传输伪装、订阅分发 |
| 控制层 | 键值存储（KV） + 边缘快照 | 订阅用户库、全局快照、跨接入点一致性 |
| 回程层 | 反向隧道（Argo Tunnel） | 在无公网入口的前提下建立节点 ↔ 边缘通道 |
| 节点层 | 住宅出口节点（代理核心 + 采集脚本） | 流量出口、分段实测、遥测上报 |
| 观测层 | 运营监控台（单文件前端） | 状态渲染、告警呈现、历史回放 |

---

## 2. 数据流

### 2.1 转发路径（数据面）

```
客户端 → 任播边缘 → 反向隧道 → 出口节点（代理核心） → 目标
```

各段依次对应监控台的五个分段：客户端接入段、任播边缘段、隧道段、节点设备段、出口网络段。

### 2.2 遥测路径（控制面）

```
出口节点采集脚本 → 组装遥测载荷 → 上报至边缘 → 边缘聚合 → 写入本接入点快照
                                                        ↓
                                            节流写入全局快照（跨接入点）
                                                        ↓
                                              监控台读取快照并渲染
```

关键点：

1. **上报是单向的**。出口节点无公网入口，边缘无法主动获取；
2. **快照是唯一事实来源**。监控台不做任何独立推算，只渲染快照内容；
3. **全局快照承担跨接入点一致性**。非节点直连的接入点通过全局快照获得同一份数据。

---

## 3. 关键时序

### 3.1 遥测采集与上报（常态）

| 周期 | 动作 |
|---|---|
| 5 s | 读取代理核心的活动连接清单（会话权威源） |
| 6 s | 组装并上报一次遥测载荷 |
| 10 s | 巡检一个中继节点（顺序推进，55 个节点一轮） |
| 30 s | 记录一次 15 分钟滑动窗口采样点 |
| 60 s | 轮测一个跨境单播测量目标 |

### 3.2 会话状态判定

会话状态**不以流量变化推断**，而以活动连接清单为准：

| 状态 | 判定依据 |
|---|---|
| 会话活跃 | 该用户出现在活动连接清单中 |
| 会话已终止 | 曾出现，且离开清单时间在阈值内 |
| 长期无会话 | 离开清单时间超过长阈值 |
| 无会话记录 | 从未出现在清单中，且无任何计量痕迹 |

跨接入点一致性由以下方式保证：**判据只使用快照内已同步的字段，不使用任何接入点本地观察量**。

### 3.3 探测并发控制

节点侧共有 4 个会产生网络探测的进程。为避免探测流量挤占住宅上行，采用**目录原子性实现的许可机制**：

| 项 | 值 |
|---|---|
| 并发上限 | 2（硬性） |
| 实现方式 | 目录创建的原子性（`mkdir` 成功即获得许可） |
| 死锁防护 | 许可内记录持有者进程号，持有者退出则回收 |
| 观测方式 | 等待超时写入日志，用于识别容量不足 |

## 4. 主要设计约束

| 约束 | 说明 |
|---|---|
| 无固定公网入口 | 源站入口完全由反向隧道建立，边缘不保存源站地址 |
| 免费额度运行 | 键值存储写入按配额节流，快照写入周期与额度上限对齐 |
| 观测不可造假 | 无法测量时输出空值；不使用推测值填充 |
| 计量不可逆 | 逐用户累计流量单调不减，基线重置按增量补偿 |
| 传输可穿越 | 使用 443 端口与标准 TLS 外观，避免非标准端口暴露 |
| 渲染不回算 | 监控台不参与任何状态推导，避免"前端各算一套" |

---

## 5. 扩展点

| 方向 | 接入方式 |
|---|---|
| 新增采集指标 | 在节点侧脚本追加字段并在遥测聚合层透传，前端按同一快照渲染 |
| 新增中继节点 | 追加节点清单条目即可，节点矩阵与订阅自动包含 |
| 新增订阅格式 | 在边缘订阅生成器追加模板，复用同一用户库与节点清单 |
| 多出口节点 | 节点侧脚本以实例标识区分；聚合层按实例维度存储 |
