# HELIOS · 终端设备网络出口与链路遥测平台

**HELIOS — High-fidelity Egress Link Integrity & Observability Suite**

> 终端设备网络出口与链路遥测平台 · Terminal Device Network Egress & Link Telemetry Platform

一套以**终端设备网络地址**作为业务出口、以**任播边缘网络**作为接入面、并对"客户端 → 边缘 → 隧道 → 出口节点 → 目标"全链路做**分段实测遥测**的轻量级出口平台。

不依赖云主机、不依赖固定公网入口、不依赖端口映射：出口节点的合法性来自它所在的终端设备接入网本身。

---

## 1. 设计目标与适用场景

### 1.1 目标

| 编号 | 目标 | 验收口径 |
|---|---|---|
| G1 | 业务流量从**终端设备网络原生地址**出网 | 出口地址归属终端设备接入网运营商，非数据中心网段 |
| G2 | 接入面不暴露固定入口 | 客户端仅访问任播边缘，源站入口由反向隧道建立 |
| G3 | 链路质量**可观测** | 每一段均有独立实测指标，可定位到具体分段 |
| G4 | 节点侧**可自愈** | 任一采集进程异常退出后自动恢复，无需人工介入 |
| G5 | 终端设备上行**可计量** | 上下行吞吐、峰值、拥塞均落库并可回溯 |
| G6 | 遥测数据**可信** | 无法测量时输出空值（`--`），不填补推测值 |

### 1.2 适用场景

- 需要对端到端链路做**分段归因**的小规模出口运营；
- 需要终端设备地址出口、但**不具备固定公网入口条件**的部署；
- 需要长期观察**跨运营商、跨境接入质量**的链路评估场景。

### 1.3 非目标

- 不提供多租户计费、审计合规等运营面能力；
- 不以高并发转发为目标（出口节点为单台设备，容量上限即终端设备上行带宽）。

## 2. 系统架构

```
客户端 ──HTTPS/443（VLESS + XHTTP + TLS）──▶ 任播边缘（Worker）
   │                                            │  · 订阅配置分发
   │                                            │  · 遥测聚合与快照
   │                                            │  · 运营监控台（单文件）
   │                                            │
   │                                            ▼
   └──────────── 遥测上报（约 6 s 周期）──── 反向隧道（Argo Tunnel）
                                                │
                                                ▼
                                        终端设备出口节点（Xray + 隧道客户端 + 采集脚本）
                                                │
                                                ▼
                                            目标网络
```

### 2.1 组件职责与故障影响面

| 组件 | 职责 | 故障影响面 |
|---|---|---|
| 客户端 | 流量封装、规则分流、择优接入 | 仅该客户端不可用 |
| 任播边缘（Worker） | 就近接入、传输伪装、订阅分发、遥测聚合、监控台 | 系统级不可用 |
| 反向隧道（Argo Tunnel） | 在出口节点与边缘之间建立回程通道 | 全量客户端不可用，遥测中断 |
| 终端设备出口节点 | 代理核心、隧道客户端、全部采集脚本 | 全量客户端不可用，遥测停止更新 |
| 运营监控台 | 将边缘快照渲染为可读状态 | 仅观测面不可用，转发不受影响 |
| 键值存储（KV） | 跨边缘接入点的全局快照与订阅用户库 | 回落为单接入点视图，指标一致性与订阅分发受影响 |

### 2.2 关键设计取舍

| 取舍 | 选择 | 理由 |
|---|---|---|
| 入口暴露面 | 仅暴露任播边缘 | 免固定入口、免证书轮换、免源站暴露 |
| 出口地址类型 | 终端设备网络 | 数据中心网段在多数风控模型中权重较低 |
| 遥测通道 | 节点主动上报 | 节点侧无公网入口，被动获取不可行 |
| 指标口径 | 单次 1×RTT 分段实测 | 可归因到分段，避免"端到端总耗时"不可解释 |
| 探测并发 | 硬性上限 2 | 避免探测流量挤占终端设备上行，干扰业务转发 |
| 缺测处理 | 输出空值 | 观测面不得出现推测值（见 G6） |

## 3. 功能矩阵

| 能力 | 说明 |
|---|---|
| 订阅分发 | 同一订阅用户库输出 Clash / v2ray 两种订阅格式，支持统一时延口径 |
| 传输协议 | VLESS + XHTTP + TLS，复用 443 端口，可穿越常见中间设备 |
| 反向隧道 | 基于 Argo Tunnel 建立回程，源站无需公网入口与证书 |
| 中继节点矩阵 | 55 个中继节点顺序巡检，逐节点输出可达性与 RTT |
| 分段时延遥测 | 客户端接入 / 任播边缘 / 隧道 / 节点设备 / 出口网络 五段分别实测量化 |
| 会话状态跟踪 | 以代理核心的活动连接清单为权威，输出在线、会话终止、长期无会话、无会话记录四态 |
| 流量计量 | 逐用户上下行累计（单调不减）、15 分钟与当日带宽峰值 |
| 域名分析 | 基于出口侧观测的域名访问排行，可按授权订阅用户筛选 |
| 配额治理 | 键值存储写入节流 + 全局快照，控制免费额度内运行 |
| 部署工具 | 一键部署脚本（版本注入、自动备份、失败回滚） |

## 4. 代码结构

```
edge/
  worker_deploy.js              边缘全部逻辑（订阅、遥测聚合、监控台；HTML/CSS/JS 内嵌单文件）
tools/
  cf_deploy.py                  部署入口：版本注入 / 自动备份 / 失败回滚
  check_secrets.py              提交前凭据自检
  kv_audit.py                   键值存储配额审计
  load_config.py                配置加载器
phone/scripts/                  出口节点侧运行的采集脚本
  run_daemon.sh                 完整启动入口（顺序固定）
  traffic_daemon.sh             守护进程 + 上报调度
  report_traffic.sh             组装并上报遥测；解析响应中的指令与节点清单
  ping_scheduler.sh             边缘接入点时延/丢包测绘
  edge_probe.sh                 出口节点 → 边缘 单次往返测量
  node_probe.sh                 中继节点逐个巡检
  fast_scan.sh                  全量探测轮次
  probe_gate.sh                 探测并发许可（硬性上限 2）
  intl_probe.sh                 跨境单播目标质量测量
phone/config/                   节点侧配置样例
deploy/                         一键部署脚本（分步执行）
docs/                           架构 / 部署 / 运维 / 数据模型 / 变更记录
```

## 5. 快速开始

```bash
# 1. 准备配置
cp .env.example .env        # 填写 Cloudflare 账号、KV 命名空间、隧道主机名等

# 2. 自检 + 分步部署（凭据、依赖、配置完整性）
python deploy/deploy_all.py

# 3. 部署边缘
python tools/cf_deploy.py
```

节点侧部署步骤、配置项说明与验收方法见 [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md)。

## 6. 观测口径

本平台的全部时间与状态指标遵循同一条口径纪律：

> **任何一个对外呈现的数值，都必须能回答"它由谁、在什么时刻、以什么方式测得"。**

- 时延类指标：均为**单次往返（1×RTT）实测量**，多段独立测量后按分段呈现；
- 会话类指标：以代理核心的活动连接清单为权威源，不由流量变化推断；
- 计量类指标：累计量单调不减，重置基线时按增量补偿；
- 缺测：输出空值，不输出推测值。

## 7. 安全与合规

- 仓库内**不含**任何真实凭据、域名、地址与用户标识；全部以占位符形式出现，由 `.env` 在部署时注入；
- 提交前强制运行凭据自检脚本；
- 节点侧配置样例中的敏感字段（UUID、隧道标识）一律留空。

详见 [`docs/SECURITY.md`](docs/SECURITY.md)。
